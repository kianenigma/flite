Crate scale_value

Source
Expand description

This crate exposes the Value type and related subtypes, which are used as the runtime representations of SCALE encoded data (much like serde_json::Value is a runtime representation of JSON data).

Value’s can be:

  • Encoded and decoded from SCALE bytes via ::scale_encode::EncodeAsType and ::scale_decode::DecodeAsType traits (or by calling crate::scale::decode_as_type and crate::scale::encode_as_type).
  • Parsed to and from strings by calling [crate::stringify::from_str] and crate::stringify::to_string). Parsing from strings requires the from_string feature to be enabled.
  • Serialized and deserialized via serde traits (for example, to and from JSON). They can also be serialized from and to other types with the relevant serde derives on. These require the serde feature to be enabled.
  • Accessed ergonomically via the At trait.
